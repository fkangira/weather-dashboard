
# My Experience with the CodeVibe Extension

During the development of my Weather Dashboard project, I experienced some issues with the CodeVibe extension that I still fail to understand.

After completing my project, CodeVibe showed that my code ownership was 0%, despite the fact that I typed everything on my own.

What confused me even more was that, when I checked the authorship section, some lines of code were flagged as manually written. I fail to understand how my overall code ownership could be 0% while the same extension recognized some of my code as manually written.

Another thing I noticed was that when I started writing my HTML file, immediately after typing `<!DOCTYPE HTML>`, the extension showed an AI usage score of 60%. I had just started writing the code. As I continued typing, the percentage started to decrease.

This made me question how the extension measures AI usage and code ownership. I am not sure whether there was a technical issue with the extension or whether there is something I did not understand about how it works.

I am providing the CodeVibe reports for transparency and further review. I would appreciate it if my authorship records, Git commit history, and project files could also be considered when assessing my work.

Thank you for your understanding.
